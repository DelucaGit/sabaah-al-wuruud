# Quran data: sources, licences and attribution

The files in `src/data/quran/` are generated by `scripts/build-quran-data.mjs`
(run `node scripts/build-quran-data.mjs`; add `--refresh` to re-download).
Raw downloads go to a temporary directory outside the repo
(`<os tmpdir>/sabaah-quran-raw`, or `QURAN_RAW_DIR`). The output is committed
so the app works fully offline. Regenerating from the same source files gives
byte-identical output.

## What the generator changes (and what it does not)

- **Quran text: no letters or marks are changed.** Each ayah's text is copied
  verbatim from Tanzil, with one exception: Tanzil's file prefixes the basmala
  to ayah 1 of every surah except Al-Fatiha and At-Tawbah. In the Madinah
  mushaf (Hafs numbering) that basmala is a heading above the surah, not part
  of ayah 1, so the generator removes that leading basmala from those 112
  ayahs only. The removed prefix must exactly match Tanzil's own 1:1 text,
  apart from a shadda on the first letter that Tanzil writes in 95:1 and
  97:1. Al-Fatiha 1:1 and An-Naml 27:30 keep their basmala. All other 6,124
  ayahs are byte-for-byte identical to the Tanzil file.
- Ayahs are grouped into pages using Tanzil's page start markers: a page runs
  from its start ayah up to the ayah before the next page's start.
- `surahs.json` uses Tanzil's Arabic name (`name`) and transliterated name
  (`tname`) as `nameAr` and `nameEn`.
- **Tafsir: verbatim.** The generator strips HTML tags and collapses
  whitespace, but Tanzil's `ar.muyassar` contains neither, so every entry is
  identical to the source.

## Human review

Religious text must be checked by a person before release (spec #1).
Spot-check a few random pages, verses and their tafsir against a printed
Madinah mushaf and At-Tafsir al-Muyassar, and record the result on issue #7.
